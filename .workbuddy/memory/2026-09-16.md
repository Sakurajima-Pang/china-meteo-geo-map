### 缺陷二：摘除不彻底 —— 省级图层漏摘

**同一批人造 range ring 在两个层级各存一份几何**：
- `data/100000_full.json` 的**省级广东省（`440000`）**：166.33 / 102.25 / 40.22 km²，
  圆度 0.268 / 0.872 / 0.784
- `data/440000_full.json` 的**市级汕尾市（`441500`）**：172.93 / 111.30 / 43.32 km²

上一轮的 `REMOVE_FROM = ('441500',)` **只摘了市级**，于是 ring 仍经**省级图层 `gProv`**
渲染出来 —— 表现为「摘了却还有印子」。

**排查线索**：目视复核时用脚本枚举 `#gProv` 内落在东沙实心点 ±8 单位内的元素，
发现省级 path 的 bbox 延伸到 **x=696.4**，而东沙实心点在 **x=692.7** —— 省级几何里
有东西越过东沙。据此回溯原始数据即定位。

**修复**：`REMOVE_FROM = ('440000', '441500')`。成品体积因此再减 363 字节
（1,828,399 → 1,828,036），`geo.json` 指纹 `4e677f913d2a980d`。

### 更重要的收获：我上一轮写的判据是空检查

上一轮写的是「**摘除数 == `len(AREAS)`**」。省级与市级各一份 ring 时，只摘市级那份
**摘除数仍为 3 == 声明数 3，判据通过**，而缺陷照旧。已改为三条**后置条件式**判据
（`geo.py` 门禁 1~3）：

1. **产物中不得残留任何人造轮廓**（扫描全部省级 + 市级几何）—— 拦「漏摘某层级/某单元」；
2. **每条声明都必须命中几何**（`set(AREAS) - 命中集` 为空）—— 拦「上游删掉 ring 后
   声明表过期」（此时判据 1 会**空过**：无残留自然不违规）；
3. **声明坐标附近的真实陆地恰 1 环** —— 拦「被面积过滤提前剔掉」（此时判据 1、2 都通过）。

三者互补、缺一不可，且**都有对应的注入回归**：

| 注入 | 检出者 |
|---|---|
| `REMOVE_FROM` 漏掉省级 `440000` | 门禁 1：`产物中仍残留人造轮廓（3 处）：省级 广东省(440000)` ✓ |
| 声明表加一条数据中不存在的条目 | 门禁 2：`声明表未在数据中兑现：ghost_bank` ✓（门禁 1 未触发，证明两者独立） |
| `MIN_AREA_CITY` 0.00005 → 0.0002 | 门禁 3：`真实陆地缺失` ✓（门禁 1、2 均通过） |
| `is_synthetic` 去掉面积判据 | 门禁 1（残留 4 处）✓ |
| 产物中直接删掉汕尾的东沙 part | `verify_isles.js` 两条判据 ✓ |

**教训（已写入 MEMORY.md 验证原则第 6 条）**：**数枚数式的判据几乎总是空检查** ——
只要存在多个可摘之处，漏摘其中一处时枚数不变。应改为「后置条件（不许存在残留）」
+ 「正向兑现（每条声明都要被命中）」。
