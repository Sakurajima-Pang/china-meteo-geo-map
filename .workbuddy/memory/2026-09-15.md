### Git / 网络环境坑（复用）
- **`gh repo create` 传中文仓库名会被静默丢弃** → 仓库名变成字面量 `-`。用 Python + `urllib`
  直连 `POST /user/repos` 并传 `ensure_ascii=False` 的 UTF-8 body，**仍**得到 `-`。
  **根因已确认：GitHub 平台本身会剔除仓库名中的非 ASCII 字符**（返回的 name 是 `-`，
  纯 ASCII 名则正常）——这是平台约束，不是本地编码问题。中文名只能放在 description / README。
  → 仓库名一律用 ASCII（本次最终为 `china-meteo-geo-map`）。
- **`git push` 报 `schannel: failed to receive handshake, SSL/TLS connection failed`** →
  `git config http.sslBackend openssl` 即解。
- 本机 `git` 走代理时偶发 `CONNECT tunnel failed, response 502`，**重试即可**（或依赖用户的 TUN 代理）。
- `zip` 命令不存在，打包用 Python `zipfile`（`compresslevel=9`）。
